# NOVA — один официальный Android-продукт

Главная цель: одна постоянно обновляемая NOVA с локальными моделями, чатом,
режиссёрским советом, инструментами и изображениями.

## Каноническая линейка

- Официальный пакет Android: `ai.nova.director.stable`.
- Для каждого официального выпуска используются **одни и те же** постоянный
  ключ `nova-stable` и публичный SHA-256 сертификата из
  `android/signing/NOVA_STABLE_CERT_SHA256.txt`.
- `versionCode` строго увеличивается. Новая Stable устанавливается
  **поверх** старой Stable, сохраняет данные и импортированные модели.
- Ни новые `applicationIdSuffix`, ни ключи debug/CI для пользовательских
  обновлений не допускаются.
- Выкладывать следует одну проверенную подписанную APK, не дюжину тестовых.
- Любое обновление должно сохранять чат, оригинальные GGUF, модели изображений,
  настройки, проекты, внутренний голос и Critic (если присутствуют).
- Отдельные debug APK остаются исключительно для CI и не предлагаются как
  обновления рабочей NOVA.

## Разовая миграция с NOVA Director Lab 1.0.1-nativeimage

Имеющаяся у пользователя версия `1.0.1-nativeimage` собрана как debug-приложение
с другим Android applicationId и, как правило, временным CI-сертификатом.
Её нельзя подменить официальной Stable APK в обход проверки подписи Android.

Процедура **один раз**:
1. Сохранить обе оригинальные модели в `Download/NOVA-Models`:
   - работающую текстовую Gemma (`.gguf`);
   - проверенную Stable Diffusion 1.5 (`.safetensors`).
2. Не удалять и не очищать `1.0.1-nativeimage` до успешной миграции.
3. Установить официально подписанную Stable рядом с прежней версией.
4. В Stable открыть «Мозги» → «Другие модели и управление»;
   импортировать Gemma GGUF и восстановить SD1.5 из `NOVA-Models`.
5. Проверить офлайн-чат, совет, создание PNG и сохранение в Галерею.
6. История чата старой debug NOVA остаётся в её private WebView-хранилище;
   **не утверждать**, что она автоматически переносится между пакетами.
   При необходимости сохранить историю до удаления старой версии.
7. Только после подтверждения владельца убрать старые debug-приложения.

## Сборка

Источник проверенного компактного Director Lab: commit
`81a5d9a1fe9aeb0c0b6fef66b8419280a3d94cb0`.
Workflow: `.github/workflows/nova-one-stable.yml`.
Он запускает тесты, сборку, проверку APK, подписи и package ID;
артефакт/релиз выпускается только после успешной проверки.

Не устанавливать на телефон необязательные экспериментальные APK для проверки
одного изменения интерфейса. Новую рабочую функцию сначала проверить CI,
потом включить в следующий официальный Stable-релиз.
